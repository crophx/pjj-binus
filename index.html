Technical Blueprint

Rancangan Use Case, Database (ERD), & Arsitektur Sistem

Spesifikasi Teknis Sistem Early Warning & Evaluasi Capaian LO PJJ BINUS (React/Next.js + Python FastAPI + MySQL)

9 Tabel Relasional 3 Aktor + 2 Model ML

1. Rancangan Use Case Berdasarkan 3 Role Pengguna

👨‍🎓 Aktor 1: Mahasiswa Self-Awareness

Goals: Lebih aware terhadap aktivitasnya di LMS setiap sesi.

  • UC-01: Melihat daftar kelas yang diikuti pada semester berjalan.
  • UC-02: Memilih navigasi Sesi 1 s/d Sesi 16.
  • UC-03: Menerima Alert Risiko Tinggi/Sedang pada sesi aktif.
  • UC-04: Melihat grafik Log Activity (LN, PPT, VBL, FD).
  • UC-05: Melihat tabel 9 Komponen Nilai (TP 1–2, TK 1–4, Quiz 1–2, Final Exam) & status gembok sesi.
👨‍🏫 Aktor 2: Dosen Early Intervention

Goals: Memotivasi mahasiswa yang kurang aktif di kelas atau personal.

  • UC-06: Menambah & mengelola kelas yang diampu.
  • UC-07: Memfilter Capaian LO (LO1 Knowledge, LO2 Skills, LO3 Analysis) per instrumen tugas.
  • UC-08: Memantau grafik rata-rata aktivitas kelas per sesi (LN%, PPT%, VBL%, FD%).
  • UC-09: Melihat Daftar Mahasiswa High & Medium Risk beserta Probabilitas Risiko (%).
  • UC-10: Melihat tabel rekap nilai & status capaian seluruh mahasiswa.
🏛️ Aktor 3: Admin Prodi Quality Improvement

Goals: Evaluasi & rekomendasi perbaikan kualitas mata kuliah.

  • UC-11: Melihat overview capaian LO seluruh mata kuliah (Donut Chart & 5 Predikat).
  • UC-12: Membandingkan capaian LO1, LO2, LO3 antar-kelas paralel (IS21F3A–F).
  • UC-13: Melihat evaluasi 3 Aspek (LO/Course, Teaching, Engagement) hasil K-Means Clustering.
  • UC-14: Menerima Rekomendasi Perbaikan Mata Kuliah berprioritas.
  • UC-15: Membedah 15 sub-indikator detail per kelas & dosen.

2. Rancangan Skema Database Relasional (ERD - 9 Tabel Utama)

File SQL siap pakai tersedia di: c:\laragon\www\pjj_binus\database_schema.sql

MySQL / PostgreSQL
1. usersMaster Aktor
🔑 id (BIGINT, PK)
• nim_nip (VARCHAR, UNIQUE)
• name (VARCHAR)
• email (VARCHAR)
• role ENUM('mahasiswa','dosen','prodi')
2. coursesMaster Matkul
🔑 id (BIGINT, PK)
• course_code (VARCHAR) e.g. IS21F3
• course_name (VARCHAR)
• curriculum_year (INT) e.g. 2021
• avg_lo_score (DECIMAL)
3. classesKelas Paralel
🔑 id (BIGINT, PK)
🔗 course_id (FK → courses.id)
🔗 dosen_id (FK → users.id)
• class_code (VARCHAR) 01PA / IS21F3A
• period (VARCHAR) 2221
• semester ENUM('Ganjil','Genap')
4. enrollmentsKRS Mahasiswa
🔑 id (BIGINT, PK)
🔗 class_id (FK → classes.id)
🔗 mahasiswa_id (FK → users.id)
• capaian_status ENUM('Berisiko Tinggi','Berisiko Sedang','Aman')
5. session_activity_logsBehavior + ML
🔑 id (BIGINT, PK)
🔗 enrollment_id (FK → enrollments.id)
• session_number (INT 1..16)
• download_materi_ln (DECIMAL 0..10)
• lihat_handout_ppt (DECIMAL 0..10)
• video_learning_vbl (DECIMAL 0..10)
• forum_discussion_fd (DECIMAL 0..10)
🤖 risk_probability (DECIMAL) 70.7%
🤖 risk_level ENUM('High','Medium','Safe')
6. assessment_configs9 Tugas & Lock
🔑 id (BIGINT, PK)
🔗 course_id (FK → courses.id)
• code ('TP1','TP2','TK1'..'FINAL')
• unlock_session (INT 1..16)
• weight_lo1, weight_lo2, weight_lo3
7. student_assessmentsKognitif LO1-3
🔑 id (BIGINT, PK)
🔗 enrollment_id (FK → enrollments.id)
🔗 assessment_config_id (FK)
• total_score (DECIMAL)
• lo1_knowledge_score (DECIMAL)
• lo2_skills_score (DECIMAL)
• lo3_analysis_score (DECIMAL)
8. class_prodi_evaluations3 Aspek + K-Means
🔑 id (BIGINT, PK)
🔗 class_id (FK → classes.id)
• avg_lo1, avg_lo2, avg_lo3, avg_lo_total
• 5 Kolom Indikator Course Design
• 5 Kolom Indikator Teaching Dosen
• 5 Kolom Indikator Engagement LMS
🤖 kmeans_predikat ('Tinggi','Sedang','Rendah')
9. course_recommendationsInsight Prodi
🔑 id (BIGINT, PK)
🔗 course_id (FK → courses.id)
• aspect_category ('Course Design','Teaching','Engagement')
• priority ENUM('Tinggi','Sedang','Rendah')
• recommendation_text (TEXT)
